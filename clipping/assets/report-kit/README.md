# report-kit — cópia de reserva do motor de desenho dos relatórios

`reports-lib.js` + as duas fontes (Unbounded e Manrope, SIL Open Font License 1.1) vêm do
repositório da dashboard (IBBA-Research-Dashboard). O HTML do WhatsApp do clipping
(`clipping/whatsapp.py`) usa primeiro a versão PUBLICADA (raw do GitHub, `main`); esta
cópia só entra se a rede falhar.

Atualizar: `python -m clipping.sync_report_kit` (baixa a publicada) ou
`python -m clipping.sync_report_kit --from <pasta da dashboard>`.
